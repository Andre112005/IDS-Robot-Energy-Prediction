# IDS Robot Energy Prediction

Machine learning and data analysis project completed as part of the KIT IDS Programming Challenge.

## Project Overview

The project focused on predicting the energy consumption of mobile robots using operational data. Our five-member engineering team explored multiple modelling approaches, including Linear Regression, Random Forest, and Support Vector Regression.

My individual responsibility was the development and evaluation of the **Linear Regression model**.

## My Contribution

- Explored and visualized the robot energy dataset
- Cleaned missing values and removed unnecessary features
- Converted categorical robot labels into numerical values
- Selected relevant input features for energy prediction
- Split the dataset into training and testing sets
- Built a Linear Regression model using scikit-learn
- Evaluated model performance using Mean Squared Error (MSE)
- Tested the trained model on previously unseen assessment data
- Presented the methodology and results as part of the team's final technical presentation

## Tools & Technologies

- Python
- pandas

- Matplotlib

## Model

The Linear Regression model used the following features:

- Distance
- Number of levels
- Elevation
- Time of day

The model was trained using an 80/20 training-test split and evaluated using Mean Squared Error.
